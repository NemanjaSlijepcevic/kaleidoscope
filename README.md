# Kaleidoscope Project

A Django-based image gallery for managing uploads and metadata (authors, places, years, categories, and descriptions) with fast browsing, filtering, and an in-page lightbox.

## Features

- Store and manage image entries:
  - Image title, description, and file
  - Author(s)
  - Place
  - Year
  - Categories
- Search by title and filter by author, place, year, and categories.
- Lightbox view with keyboard navigation and optional watermarking.
- Thumbnail-based gallery for faster browsing.
- User-friendly interface for adding, updating, and deleting entries.

## Tech Stack

- **Backend:** Django (Python)
- **Database:** SQLite
- **Dependencies Management:** `pip`
